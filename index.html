Data Science & Library Research

Welcome to the Data Science & Librarianship Guide

Welcome! This guide was created as part of my MLIS coursework to explore how data science is transforming modern librarianship. As libraries continue to evolve, understanding data and how it's collected, analyzed, and used, has become essential for supporting research, improving user experiences, and making informed decisions.

Use the navigation above to explore research sources, practical tools, and reflections on the evolving role of data in the information field.

What This Guide Includes

This LibGuide-style website introduces core concepts of data science, highlights tools and resources to build data skills, and reflects on my own learning journey as an MLIS student. You’ll find recommended readings, examples of how libraries use data, and personal insights based on my coursework.

Who This Guide Is For

This guide is designed for MLIS students, early-career librarians, educators, and anyone curious about the intersection of data science and library work. Whether you are new to the topic or developing technical skills, this guide provides accessible starting points and real world examples.
